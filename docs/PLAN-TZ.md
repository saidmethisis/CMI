## Блок 2. Панель автора ✅

| Требование | Состояние |
|---|---|
| Ввод текста сразу на 3 языках в одном окне | ✅ вкладки UZ/RU/EN, точка отмечает заполненный язык |
| Продвинутый Rich Text Editor | ✅ форматирование, 3 размера шрифта, выравнивание, списки, ссылки, картинки |
| Отдельный стиль для цитат | ✅ акцентная линия, крупный кегль, приглушённая подложка |

**Почему редактор свой, а не готовая библиотека.** В ТЗ прямым текстом: «сайт
должен быть легковесным, мгновенно загружаться». Любой известный редактор —
это ProseMirror на две-три сотни килобайт. Здесь ту же работу делает браузер,
нам остаётся панель кнопок и строгая уборка за ним.

**Безопасность.** Текст из редактора — это HTML, то есть готовый канал для
XSS. Он моется санитайзером с белым списком тегов дважды: при сохранении и при
выводе. 30 проверок, включая скрипты, обработчики событий, `javascript:` в
ссылках, `data:text/html` в картинках, `svg` с `onload` и подделку class.

Старые статьи не сломались: текст без разметки выводится как раньше, формат
определяется по содержимому.

## Блок 3. Модерация и панель суперадмина ✅

| Требование | Состояние |
|---|---|
| Страница проверки = копия страницы автора, с полноценной правкой | ✅ |
| Массовая загрузка 5–10 изображений с распределением по тексту | ✅ до 10 за раз |
| Дашборд связан с реальной базой | ✅ |

Правка не отправляет материал на повторную модерацию — он уже в очереди, и
решение принимает тот же человек. Правка опубликованного материала уведомляет
Google, иначе в выдаче осталась бы старая версия с ошибкой.

Файлы при массовой загрузке уходят по очереди, а не залпом: десять снимков с
телефона на мобильном интернете чаще срываются, чем проходят.

Дашборд: метрики, графики публикаций и просмотров, разбивка по рубрикам, топ
материалов — из базы. Добавлена динамика комментариев по месяцам.
